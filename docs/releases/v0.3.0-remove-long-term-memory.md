# v0.3.0 — Long-Term Memory Removed

**Date:** 2026-08-21 · **Previous:** 0.2.4 · **Commits:** `d82da7d`..`cd8136f`

> Reconstructed from git history on 2026-08-25.

**Breaking.** Long-term memory was the one surface that wrote outside
`.as-usual/`, and the one runtime skill whose value did not survive a cold
session: recall was untrusted by design, so every recalled fact had to be
re-checked against disk before use, and the `finalize` memory pass ran on every
close whether or not the unit had taught anything reusable.

## What Goes Away

- The `search-long-term-memory` skill — runtime skills drop from fifteen to
  **fourteen**.
- `templates/MEMORY.md`, `docs/memory/MEMORY.md`, and
  `references/memory-update.md`.

`manage-self-improvement` keeps only the half that produces something
executable — a project-local skill — and `finalize` invokes it only when a
credible candidate exists. Facts, decisions, preferences, and one-off lessons
now live in the work unit's own artifacts, which is where a later session reads
from anyway.

## Record Compatibility

The `memory` event kind moves from `KINDS` to `RETIRED_KINDS`: released records
that already carry it still pass `validate`, while `add` refuses to write a new
one. Both retired-kind tests are parametrized over `artifact` and `memory`.

## Also Fixed

Two defects found while sweeping the surface: the README `.as-usual/` tree kept
`│` continuation glyphs under what is now its last entry, and `git-action` had
`direct-work` without its trailing slash. The two affected architecture diagrams
were recaptured at the same width as the other five.

## Verified At Release

`pytest scripts/tests/ -q` — 97 passed · `jq empty` over all six manifests ·
hook smoke · `ls skills/` is exactly fourteen · no `search-long-term-memory`,
`docs/memory`, or `MEMORY.md` reference outside dated history.
