# v0.2.3 — The Auto Mode Is Reverted

**Date:** 2026-08-10 · **Previous:** 0.2.2 · **Commits:** `9e7f50e`..`3776a44`

> Reconstructed from git history on 2026-08-25.

A single decision, shipped as its own release.

## What Was Removed

The opt-in auto mode introduced in 0.2.2 as a fourth runtime rules file is
reverted. A mode that lets the harness carry itself forward without the user's
decisions contradicts what the record layer is for: the gates are about
permission and durable evidence, not about the agent's capability. A fourth
rules file also broke the rule that the runtime contract lives in exactly three
files.

## What Was Kept

The revert had taken a documented lesson with it — the false-pass verification
case — which is restored on its own. That lesson is what the finalize gate work
in 0.2.4 acts on.
