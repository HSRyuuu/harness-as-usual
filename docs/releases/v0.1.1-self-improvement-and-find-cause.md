The largest 0.x release. Three things arrive: a second work unit for
investigation, a self-improvement surface, and marketplace-based installs.

## find-cause — Investigation Without Changing Code

A whole second workflow for confirming a cause before touching anything:

- `journal-log.py` with its own record — init, add, approve, status-change
  (confirm/cancel), derived status, view rendering, structural validation.
- A **conclude gate**: an issue cannot conclude without evidence, and
  `conclusion.md` is required before it closes.
- Post-conclusion mutation is blocked, and approvals after a conclusion are
  refused.
- `problem.md` and `conclusion.md` templates, the `find-cause` runtime skill,
  activation routing, a hook entry point, and `link-follow-up` for linking a
  concluded issue to the topic that acts on it.

## Self-Improvement And Long-Term Memory

- `manage-self-improvement` and `search-long-term-memory` skills,
  `MEMORY.md` template, memory/skill audit event kinds.
- Memory candidates captured during requirements, plan, and execute; recall wired
  into activation and requirements; `.as-usual/memory` artifacts became
  committable; the hook announced project memory when present.

*(Both surfaces were removed again in 0.3.0 — see that note for why.)*

## Verification Receipts

Verification stops being prose. Verdicts are required, execution and review
receipts are standardized, and the receipt verdict contract is documented and
tested. This is the ancestor of core rule 3.

## Also In This Release

- **Hook slimmed** to an activation hint instead of injected rules.
- **`topic-log.py` split** from one file into the `as_usual_topic_log/` package.
- **New skills**: `explore-codebase` for read-only discovery, `hand-off` for
  cross-session resume.
- **The fable improvement round** (F1–F13): clarification routing on a
  focused/broad model, a severity-based finding disposition matrix, cancel and
  `direct-execute` terminal paths, English canonical template headings, and the
  hook's host-format branches documented as experimental.
- **Question audit macros** and a canonical audit command reference.
- **Reviewer calibration** for task, execution, and cleanup reviews.
- **Marketplace identity** for installs: `as-usual@harness-as-usual` replaces the
  path-based install as the documented route.
