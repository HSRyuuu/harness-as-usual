Work units

Three peers, not three stages

Each unit is a different kind of work with its own shape. The step skills are shared and unit-agnostic — the difference lives in which steps apply, in what order, and at what strength.

Confirming the cause and stopping there is a normal ending for an issue — a concluded issue does not become the fix, it links to one.  ·  A folder can still be relabelled (move) until it has produced requirements.md, plan.md, or conclusion.md; after that it takes a new folder and a two-way link.
