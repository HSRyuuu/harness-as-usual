You pick — it does not argue. The agent classifies and recommends with a reason, then presents all four options once. Choosing against the recommendation ends the discussion; there is no re-pitch.
Size is not a criterion. A mechanical rename across thirty files is direct-work. A two-line change to how sessions expire is not. Ambiguity and risk are what push work up to topic.
Resume from disk, not from chat. Ask to continue anything and using-as-usual finds it — whether this session started it or another one, days ago, did.
