You pick — it does not argue. The agent recommends with a reason, then presents all four options once. Choosing against the recommendation ends the discussion; there is no re-pitch.
Size is not a criterion. A mechanical rename across thirty files is direct-work. A two-line change to how sessions expire is not. Ambiguity and risk are what push work up to topic.
A bug with an unknown cause is an issue even when the eventual fix is one line.  ·  "Just do it" is withheld when the work is built around a high-risk operation, or falls inside an open folder's scope.  ·  Can't decide? An inbox/ folder is created, narrowed down, then moved into the chosen unit.
