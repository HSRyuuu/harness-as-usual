Entry

One door. No menu.

The SessionStart hook announces one capability and one entry point in a single sentence — no rules, no folder list. using-as-usual reads the rest from disk, sets the record up, and hands it to the one owner. What the record goes on to produce follows from the request, not from a label picked at the door.

Opt-in
Only an explicit ask activates it
  • You say as-usual or AsUsual
  • You mention .as-usual/, contexts.md, audit.jsonl, requirements.md, plan.md, conclusion.md, or a work folder path
  • You ask to resume or continue, and a work folder exists
  • You invoke the owner, run-work, directly — the folder is still created here first
Not a signal
Handled normally
  • A development or investigation request on its own
  • The hook announcement
  • A .as-usual/ folder merely being there
